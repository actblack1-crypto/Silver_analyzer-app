🥈 Silver Price Analyzer

This project is a Python and Streamlit dashboard for analyzing the SLV silver ETF. It includes price charts, technical indicators, historical data, and CSV export.

Important: This is not a standalone static website. Netlify cannot run the Python/Streamlit application from this ZIP by itself. The dashboard must be run with Streamlit or deployed to a service that supports Streamlit.

Run the dashboard

  1. Install Python 3.10 or newer.
  2. Open a terminal in this project folder.
  3. Run py -m pip install -r requirements.txt.
  4. Run py -m streamlit run silver_analyzer.py.

For Windows desktop packaging, run build_windows.bat on a Windows computer.

See README.txt for full instructions.
